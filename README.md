# Networkwalks Cybersecurity Internship

Documentation and practical work completed during my Networkwalks Cybersecurity Internship.

## About This Repository

This repository documents my hands-on learning and practical work throughout my cybersecurity internship.

It contains lab setups, network configurations, troubleshooting steps, practical exercises, screenshots, and key learning outcomes. The repository is organized by week and phase to keep the work structured and easy to follow.

## Week 01

### Phase 1 — Cybersecurity Lab Setup

The first phase focused on setting up the initial virtual cybersecurity lab environment using VirtualBox and Kali Linux.

#### Topics Covered

- 7-Zip installation
- VirtualBox installation
- NAT Network configuration
- Kali Linux virtual machine setup
- IPv4 network configuration
- DNS configuration
- Network routing
- Gateway connectivity testing
- Network troubleshooting using NetworkManager (`nmcli`)
- Kali Linux snapshot creation

#### Network Configuration

| Component | Configuration |
|---|---|
| Network Type | NAT Network |
| Network Name | `NATNetwork` |
| IPv4 Network | `10.0.0.0/24` |
| DHCP | Enabled |
| Kali Linux IP | `10.0.0.2/24` |
| DNS | `8.8.8.8` |
